# Performance Benchmark

Use this skill when an agent needs to measure web performance.

## Process

1. Establish or load a baseline.
2. Measure page load and key web vitals.
3. Compare before and after when possible.
4. Identify resource or runtime causes.
5. Report regression risk with evidence.
