# Office Hours

Use this skill when an agent needs to help a founder think through an idea.

## Process

1. Identify the user and painful status quo.
2. Ask what makes the problem urgent.
3. Narrow the first wedge.
4. Separate observed demand from imagined demand.
5. End with next concrete validation step.
