# Web App QA

Use this skill when an agent needs evidence-driven QA for a web application.

## Process

1. Identify the critical user flows.
2. Test the app in a browser, not only by reading code.
3. Capture failures with repro steps and screenshots when possible.
4. Re-test after fixes.
5. Separate critical issues from cosmetic polish.
