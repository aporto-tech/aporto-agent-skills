# Design Review

Use this skill when an agent needs designer-level QA on a UI.

## Process

1. Inspect hierarchy, alignment, spacing, type, color, and density.
2. Check mobile and desktop breakpoints.
3. Find overlapping text, unstable controls, and weak visual rhythm.
4. Compare before and after if fixes are made.
5. Prefer concrete visual issues over vague taste notes.
